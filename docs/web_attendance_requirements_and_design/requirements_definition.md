# Webでの勤怠確認と修正の要件定義

## 概要
Discordで記録した出勤と退勤の時刻を、ブラウザで確認できる機能です。
勤怠の一覧では、1回の出勤ごとに、出勤した日、出勤した時間、退勤した時間、その出勤で働いた時間を表示します。
月ごとの総労働時間と出勤回数もまとめて確認できます。
打刻を間違えたり忘れたりした時は、従業員がDiscordで社長に伝え、社長がWebで記録を修正します。

## きっかけ
- 社長が月末にバイトの子の勤務時間を集計していて手間がかかっている。
- 給与計算の時に、誰が何日の何時から何時まで働いたかをすぐに確認したい。
- バイトの子から「今月何時間働いたか」を聞かれることがあるので、本人も確認できるようにしたい。
- 打刻を間違えたり忘れたりした時に、正しい記録に直す手段がない。

## 誰に向けて
- 社長(全員の勤怠を確認し、記録を修正する人)
- 会社のバイトの子(自分の勤怠を確認する人)

## どんな時に使うか
- 月末に給与計算のため、勤務時間を確認する時
- バイトの子が、自分がいつどれくらい働いたかを確認したい時
- 打刻を間違えた時や、退勤し忘れた時(従業員がDiscordで社長に伝え、社長がWebで直す)

## アプリ全体でできること
このアプリは、実際に働いた勤怠の打刻、確認、修正のみを扱う。

| 使う場所 | 従業員 | 社長 |
| --- | --- | --- |
| Discord | 打刻する、自分が出勤中か確認する | 全員の出勤状況を確認する |
| Web | 勤怠を確認する、自分の記録の修正履歴を確認する | 全員の勤怠を確認する、記録を修正する、全員の修正履歴を確認する |

Discordでの打刻と出勤状況の確認の詳しい内容は、[discordでの出退勤の要件定義](../attendance_requirements_and_design/requirements_definition.md)を参照。

## どんな機能が必要か
### 必須
#### 勤怠の確認
- 出勤の記録を一覧で確認する
  - 社長は全員の記録を見られる。バイトの子は自分の記録だけ見られる
  - 一覧には、出勤日、出勤時間、退勤時間、その出勤の合計勤務時間を表示する
  - 1回の出勤を1行にする。会社は自由出勤のため、1日に複数回出勤することがある
- 日をまたいだ勤務(例:10/3 21:30出勤、翌0:30退勤)は1行で表示し、日をまたいでいることが分かるようにする
- 月をまたいだ勤務は、出勤日の月の勤務として扱う(例:10/31 21:30出勤、11/1 0:30退勤は10月の勤務)
- まだ退勤していない記録があることが分かるようにする(退勤し忘れに気づけるようにするため)
- 月ごとの総労働時間と出勤回数を確認する
- 今月だけでなく、過去の月の記録も選んで確認できる
- 社長は、人を選んでその人の記録だけを表示できる(給与計算の時に1人ずつ確認するため)

#### 記録の修正
- 記録を修正できるのは社長だけとする
- 社長はWebで記録を直接修正する。修正では次のことができる
  - 出勤時間・退勤時間の変更
  - 打刻し忘れた出勤の追加
  - 間違えた出勤の削除
- 従業員は打刻を間違えた時、Discordで社長に伝える
- 修正した時は、必ず修正履歴を残す(トラブルが起きた時に、いつ何を直したかを確認できるようにするため)
  - いつ、誰の、どの記録を、修正前から修正後にどう直したかを残す
  - 修正履歴はWebで確認できる。社長は全員の修正履歴、バイトの子は自分の記録の修正履歴だけを見られる
  - 修正履歴はWebから変更・削除できないようにする

### 次のバージョンで検討
15日で作る必要があるため、今回は次の機能を作らない。
- 勤怠修正申請の流れ(従業員がWebから申請する → 社長が承認・却下する → Discordのサーバーに通知する)
- 会社の外(スマホや家など)から見られるようにすること
- 記録をCSVなどのファイルに書き出すこと

### やらないこと
- Webからの打刻(打刻はDiscordで行う)
- シフト管理、給与計算そのもの
- 打刻の修正以外の申請(休暇、残業など)
- 休憩時間の管理
- 打刻した場所(位置情報)の記録

## 非機能要件
- 時刻は日本時間(JST)で表示する。
- Discordで記録した出退勤と同じ記録を表示する。
- 記録を修正できるのは社長だけにする。
- バイトの子が他の人の記録を見られないようにする。
- 修正履歴は、Webから変更・削除できないようにする。
- 今回は、会社の中から見られれば良い。

- 2026年10月3日の時点で、15日で作る必要があるため、機能を絞った。
- 会社の外からは見られないため、ポートフォリオに載せる時は動作を動画にして見せる。

- 基本設計で使うために、要件定義の話し合いで決まった見せ方を残しておく。
  - 日をまたいだ時の退勤時間は「翌0:30」のように表示する。
  - 一覧には出勤した日だけ並べる。
  - 退勤していない行は、退勤時間を「出勤中」、合計勤務時間を「-」と表示する。
