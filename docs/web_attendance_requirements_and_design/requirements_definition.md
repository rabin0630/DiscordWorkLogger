# Webでの勤怠確認と修正申請の要件定義

## 概要
ブラウザで出勤と退勤の打刻、勤怠の確認、打刻の修正申請ができる機能です。
勤怠の一覧では、1回の出勤ごとに、出勤した日、出勤した時間、退勤した時間、その出勤で働いた時間を表示します。
打刻を間違えたり忘れたりした時は、従業員がWebから修正を申請し、社長が承認すると記録が修正されます。
申請が来た時と、社長が承認したかどうかは、Discordのサーバーに通知されます。

## きっかけ
- 社長が月末にバイトの子の勤務時間を集計していて手間がかかっている。
- 給与計算の時に、誰が何日の何時から何時まで働いたかをすぐに確認したい。
- バイトの子から「今月何時間働いたか」を聞かれることがあるので、本人も確認できるようにしたい。
- 打刻を間違えたり忘れたりした時に、正しい記録に直す手段がない。

## 誰に向けて
- 社長(全員の勤怠を確認し、修正申請を承認する人)
- 会社のバイトの子(打刻し、自分の勤怠を確認し、修正を申請する人)

## どんな時に使うか
- 出勤した時、退勤する時(Webから打刻する)
- 月末に給与計算のため、勤務時間を確認する時
- バイトの子が、自分がいつどれくらい働いたかを確認したい時
- 打刻を間違えた時や、退勤し忘れた時

## アプリ全体でできること
このアプリは、実際に働いた勤怠の打刻、確認、修正申請、修正のみを扱う。

| 使う場所 | 従業員 | 社長 |
| --- | --- | --- |
| Discord | 打刻する、出勤中か確認する | 出勤中か確認する |
| Discordのサーバーへの通知 | 修正申請の結果を受け取る | 修正申請が来たことを受け取る |
| Web | 打刻する、勤怠を確認する、修正を申請する | 勤怠を確認する、修正申請を承認・却下する |

## どんな機能が必要か
### 必須
#### 打刻
- Webから出勤・退勤を記録する
- Discordで打刻した記録とWebで打刻した記録は、同じ記録として扱う

#### 勤怠の確認
- 出勤の記録を一覧で確認する
  - 一覧には、出勤日、出勤時間、退勤時間、その出勤の合計勤務時間を表示する
  - 1回の出勤を1行にする。会社は自由出勤のため、1日に複数回出勤することがある
- 日をまたいだ勤務(例:10/3 21:30出勤、翌0:30退勤)は1行で表示し、日をまたいでいることが分かるようにする
- 月をまたいだ勤務は、出勤日の月の勤務として扱う(例:10/31 21:30出勤、11/1 0:30退勤は10月の勤務)
- まだ退勤していない記録があることが分かるようにする(退勤し忘れに気づけるようにするため)

#### 打刻の修正
- 従業員は、自分の打刻の修正を申請する
- 記録を修正できるのは社長だけとする
- 修正の流れは「従業員が修正を申請する → 社長が申請を見て承認するか決める → 承認されたら記録を修正する」とする
- 修正申請が来たら、Discordのサーバーで社長と申請者が分かるように通知する
  - 例:「@社長、@○○さんが打刻変更申請をしました。確認お願いします。」
- 社長が承認したかどうかを、Discordのサーバーに通知する

### あったら良い
- 月ごとの総労働時間と出勤回数の集計(discordでは表示しないため、webで確認する)

### やらないこと
- シフト管理、給与計算そのもの
- 打刻の修正以外の申請(休暇、残業など)

## 非機能要件
- 時刻は日本時間(JST)で表示する。
- Discordで記録した出退勤と同じ記録を表示する。
- 記録を修正できるのは社長だけにする。

---

## 未決事項
- バイトの子が見られるのは自分の記録だけにするか。
- スマホや家など、会社の外からも見られるようにするか。会社のPCで見られれば十分か。
- 修正申請でできること。出勤時間・退勤時間の変更だけか、打刻し忘れた出勤の追加や、間違えた出勤の削除もできるようにするか。
- 修正申請に理由を書いてもらうか。却下した時に社長が理由を伝えるか。
- 申請した後に、従業員が申請を取り消せるようにするか。
- 社長が承認・却下するのはWebだけか、Discordからもできるようにするか。
- 休憩時間を記録するか(出退勤の要件定義の未決事項と同じ)。
- 打刻した場所(位置情報)を記録するか。

## メモ
- 以前作ったWebの出退勤アプリ(Task_Assist_System)の画面を土台にできそう。ただし、1日1行の一覧で、ユーザーの区別やログインがないため、記録の保存や取得はこのアプリのAPIとDBを使う。
- 基本設計で使うために、要件定義の話し合いで決まった見せ方を残しておく。
  - 日をまたいだ時の退勤時間は「翌0:30」のように表示する。
  - 一覧には出勤した日だけ並べる。
  - 退勤していない行は、退勤時間を「出勤中」、合計勤務時間を「-」と表示する。
