# タイマーの要件定義

基本設計は[basic_design.md](./basic_design.md)を参照。

## きっかけ
- タイマーを付けることでメリハリを持って作業したい。
- 作業時間を可視化して自分の努力や達成感を認識したい。
- 使っているハードウエアのタイマーはワンタッチではなく、セットの仕方が複雑で使いにくい。
- 小さな困りごとを解決しつつ、勉強もしたい。

## なぜdiscordなのか
そもそもタイマーを開発する前に、discordを使用した出退勤記録を作ろうと考えていました。
私の会社ではdiscordでコミュニケーションを取っているのですが、バイトの子が出退勤をするとき
スプレッドシートに時刻を入力して出退勤を記録していてとても手間がかかるなと思いました。
そこで、ワンクリックで出退勤の時刻を記録できるツールを作ろうと考えました。
最初はwebを使用したり、エクセルの関数を使って出退勤の記録を簡単にしようと考えましたが、
出退勤をする時社長にdiscordで挨拶をしていると聞いたので、それなら挨拶のついでにdiscordで出退勤を記録できるようにしようと思いました。
その前にdiscord.pyの使い方を学ぶために最初はタイマーを作ろうと思いましたね。

## どんなタイマーにするか(とりあえず頭に思いついたことを適当に書いていく)
### 誰に向けて
- 俺のため
- discordを起動しながら作業をする人
- 個人でも使用できるし、サーバーのチャットで起動して皆で使うこともできる
- スマホでも使用できる
### どんな時に使うか
- 勉強をする時
- ゲームで時間が決まっている時
- 作業で時間が決まっている時
### どんな機能が必要か
- できるだけシンプルなタイマー。多機能にはしない
- 分単位のみにする
- ポモドーロタイマー
- 停止機能,一時停止、再開機能
- ユーザーが指定した時間を記憶させ、次回以降はその時間でワンクリックで起動できるようにする

## メモ
- シンプルなタイマーにするか多機能なタイマーにするか悩む。
  機能を拡張しようと思えばいくらでもできるが、シンプルなほうがユーザーは使いやすい。
  また、出退勤の機能がメインとなるため、ここではある程度妥協をしてもいい気がする。
