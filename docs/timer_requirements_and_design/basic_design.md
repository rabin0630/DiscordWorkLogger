# タイマーの基本設計

要件定義は[requirements_definition.md](./requirements_definition.md)、詳細設計は[detailed_design.md](./detailed_design.md)を参照。

## コマンド設計
- コマンド形式はスラッシュコマンド
- 個人で使用する時はbotに直接メッセージを送ってコマンドする
- サーバーで皆でタイマーを使用する時はサーバーのチャットでコマンドする
- /start で指定した時間のタイマー開始。デフォルトは15分
- /stop でタイマー停止
- /pause でタイマー一時停止
- /resume でタイマー再開
- /remaining で残り時間表示
- /pomodoro でポモドーロタイマー開始。デフォルトは25分
- /set_timer でタイマーの時間を指定する。

## データモデル設計
- データベースはMysqlを使用し、メモリでの保存は辞書を使用する。
- ユーザーが指定したタイマーの時間はデータベースに保存する。
- 動作中のタイマーの状態(動いているか、残り時間)はメモリに保存する。
